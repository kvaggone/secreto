# Secreto crypto library

This package contains the natives crypto primitives used by the [Secreto lib and project](https://secreto.info). It is a standalone package built to provide compatibility between different environments by exposing the same API for node:crypto and web SubtleCrypto.

## Installation

```bash
# with npm
npm install @secreto/crypto

# with yarn
yarn add @secreto/crypto

# with pnpm
pnpm add @secreto/crypto
```
