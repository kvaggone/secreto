# Secreto Brand Kit

Welcome to the Secreto Brand Kit. Here, you'll find resources to help you represent Secreto accurately in media and press coverage. Secreto is an open-source web application designed for private, end-to-end encrypted note and file sharing.

## Project Overview

**Secreto** is a minimalistic, secure web app enabling users to send encrypted notes and files with end-to-end security. The platform prioritizes user privacy by ensuring that servers have zero knowledge of the contents shared. For a complete overview of features, see the [README](https://github.com/kvaggone/secreto).

## Key Features

- **End-to-End Encryption**: Your notes are encrypted on the client side, using AES-GCM with a 256-bit key derived using PBKDF2.
- **Email Access Gate**: Lock a note to specific recipients, who unlock it with a 6-digit one-time code sent by email.
- **File Attachments**: Share files securely with your notes.
- **Zero Knowledge**: The server does not have access to the content of the notes or files.
- **Configurable Security Options**: Set a password, expiration time, and choose self-destruction after the note is read.
- **Live Expiration Countdown**: Recipients see exactly how long they have before a note expires.
- **Minimalistic UI**: Simple and intuitive user interface for quick note sharing.
- **i18n Support**: Available in multiple languages.
- **Authentication**: Optional email/password authentication to create notes.
- **Dark Mode**: A dark theme for late-night note sharing.
- **Responsive Design**: Works on all devices, from desktops to mobile phones.
- **Open Source**: The source code is available under the Apache 2.0 License.
- **Self-Hostable**: Run your instance of Secreto for private note sharing.
- **CLI**: A command-line interface for creating notes from the terminal.
